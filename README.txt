EQUATION LAB — BALANCE & SOLVE
Standalone interactive algebra activity

GET STARTED
1. Extract the ZIP file, if using the ZIP version.
2. Double-click index.html.
3. It opens in Chrome, Edge or another modern browser.
4. No internet connection, additional libraries, Python or installation required.

HOW TO PLAY
- Select One-step, Two-step or Multi-step.
- Move a blue x tile or a gold constant tile to the opposite side of the balance.
- Drag with your mouse or finger, OR click a tile and then click the other pan.
- The activity applies the corresponding inverse operation to BOTH sides.
- Use the balance toolkit to divide or add/subtract equal amounts on each side.
- For bracket equations, use Expand brackets first.
- Use Undo, Reset, Hint and Reveal exemplar as needed.
- Each level currently has four equations.

TEACHING NOTE
The scale is a conceptual balance representation rather than a physical weight
simulation: terms can include negatives, so the pans represent algebraic
expressions. Transposing a term is always explained as an equivalent inverse
operation applied to both sides, not as an unexplained sign flip.

All calculations are performed locally in your browser. No student information
is collected or transmitted.
